# 3사단 의무대대 치과 홈페이지

## 열어 보기
`index.html` 을 더블클릭하면 브라우저에서 열립니다. 네 페이지가 서로 연결되어 있습니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 홈: 첫 화면, 진료 과목 3개, 진료 시간표, 자주 묻는 질문, 예약 문의 |
| `clinic.html` | 진료 안내 |
| `hours.html` | 진료 시간과 예약 방법 |
| `care.html` | 치료 전후 주의사항 |
| `style.css` | 모든 페이지의 모양 |
| `site.js` | 안내판의 실시간 상태, 그림 전환, 드러나기 효과 |
| `screenshots/` | 데스크톱·휴대폰 캡처 |

## 글을 고치려면
`src/pages/` 안의 파일을 고친 뒤 터미널에서 `node build.mjs` 를 실행하세요. 공용 부품(머리말, 그림, 안내판, 마지막 섹션, 꼬리)은 `src/` 에 하나씩 있습니다.
완성된 `*.html` 을 직접 고쳐도 되지만, 그러면 빌드를 다시 돌릴 때 덮어써집니다.

## 출시 전에 꼭 바꿀 것
- 전화번호 `000-0000-0000` 과 내선 `000-0000` (네 페이지 모두, `src/cta.html`, `src/pages/hours.html`)
- 위치 "의무대대 본부 1층 치과 진료실", 오시는 길 설명
- 진료 시간 (안내판 `src/board.html`, 주간 시간표 `src/drawings.svg`, `site.js` 의 HOURS, 각 페이지 본문)
- 장비와 인원 설명 (`src/pages/clinic.html`)
- 그림은 실제 진료실·안내판 사진이 생기면 바꾸세요. 꼬리의 "그림은 임시" 문구도 함께 지우세요.
