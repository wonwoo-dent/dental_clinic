## 글을 직접 고치는 법 (GitHub 화면에서)
1. 위 표에서 고칠 파일을 클릭한 뒤, 오른쪽 위 **연필(✏️) 아이콘**을 누릅니다.
2. 글자를 찾아 고칩니다. 찾기는 Ctrl+F (Mac은 Cmd+F). `<p>`, `<li>` 같은 꺾쇠 안의 내용은 건드리지 말고, 꺾쇠 사이의 한글만 바꾸면 안전합니다.
3. 오른쪽 위 초록색 **Commit changes...** → 다시 **Commit changes** 를 누릅니다.
4. 1~2분 뒤 홈페이지를 새로고침하면 바뀌어 있습니다.

## 글꼴을 바꾸는 법
`style.css` 맨 위쪽의 `--font:` 줄에서 맨 앞 글꼴 이름을 바꿉니다. 지금은 Pretendard(없으면 Noto Sans KR)입니다.
예를 들어 Google Fonts 의 `Nanum Gothic` 을 쓰려면, 네 HTML 파일의 `<head>` 안 `fonts.googleapis.com` 줄의 `Noto+Sans+KR` 을 `Nanum+Gothic` 으로 바꾸고, `--font:` 줄의 `"Noto Sans KR"` 을 `"Nanum Gothic"` 으로 바꿉니다.

## 사진을 바꾸는 법
`photos/` 폴더에 같은 이름으로 사진을 올리면 바로 바뀝니다 (GitHub 화면에서 **Add file → Upload files**).
- `room-chair.jpg` (세로 960×1080): 홈 맨 아래 "전화 한 통이면 됩니다" 옆 사진
- `room-unit.jpg` (가로 960×640): "오시는 길" 사진
- `wisdom-pano.jpg`, `crown-zirconia.jpg`, `exam-mirror.jpg` (가로 1400×875): 진료 과목 사진
실제 진료실 사진으로 바꾸면 홈 맨 아래 "진료실 사진은 참고용 자료 사진입니다" 줄도 지우세요.

## 진료 일정 달력 (구글 캘린더 연동)
- 의무대대 공용 구글 캘린더를 GitHub가 **한 시간마다** 읽어서, 제목에 `이원우`나 `이종철`이 들어간 일정만 골라 `data/schedule.json`에 저장합니다. 다른 군의관 일정과 휴가 종류(연가, 청원휴가 등)는 저장하지 않고, 누가 종일·오전·오후 비는지만 남깁니다.
- 캘린더에는 지금처럼 `연가1) 이원우(5/9일)`, `청원휴가3) 이종철` 식으로 적으면 됩니다.
  - `당직)` 일정은 낮 진료에 영향이 없어 무시합니다. 나머지 종류(연가, 청원휴가, 공가, 학회출장, 근무취침 등)는 모두 그날 부재로 봅니다.
  - 제목에 `오전`이나 `오후`가 있으면 반나절만 부재로 봅니다. 예: `오전반가1) 이종철`
  - 시간을 정해 넣은 일정은 09–12시, 13–16시와 겹치는 쪽만 부재로 봅니다.
- 공휴일과 대체공휴일은 구글의 '대한민국의 휴일' 캘린더에서 자동으로 가져옵니다.
- 급하게 바로 반영하려면: 저장소 **Actions** 탭 → **진료 일정 가져오기** → **Run workflow**. 1~2분 뒤 홈페이지에 반영됩니다.
- 캘린더 주소는 저장소 **Settings → Secrets and variables → Actions** 의 `CAL_MEDICAL`에 있습니다. 캘린더 관리자가 비공개 주소를 재설정하면 새 주소로 이 값만 바꾸면 됩니다.
- 군의관이 바뀌면 `scripts/build_schedule.py` 맨 위 `DOCTORS`의 이름·계급·전공을 고칩니다. 무시할 일정 종류는 `IGNORE_KINDS`에서 바꿉니다.
- 저장소에 두 달 넘게 아무 변경이 없으면 GitHub가 자동 작업을 멈출 수 있습니다. 그때는 Actions 탭에서 다시 켜면 됩니다.
