# 작업 인계: 3사단 의무대대 치과 사이트 개선

claude.ai 대화에서 정리한 피드백과 결정 사항입니다. 이 파일을 먼저 읽고 아래 체크리스트 순서대로 작업하세요.
시안 마크업은 같은 폴더의 `mockup-care.dc.html`(주의사항), `mockup-home.dc.html`(홈)을 참고하세요. 캔버스 전용 형식이라 그대로 쓰지 말고 구조·색·문구만 가져오세요.

## 1. 운영 맥락 (설계의 전제)

- 사이트: https://wonwoo-dent.github.io/dental_clinic/ (GitHub Pages, 정적 HTML)
- 배포 경로: QR은 부대 내 카메라 금지로 불가 → **카카오톡 채널 친구추가 후 링크**로 제공 예정
- 용사는 **일과 중 휴대폰이 없음**. 일과 후 저녁에 링크를 읽고, 다음 날 **행정반 군 전화**로 예약함
- 내선 803-7112는 평일 09–16시, **군 전화로만** 연결됨 (개인 휴대폰으로는 못 검)
- 보철: 기공물이 도착하면 기공소가 용사 휴대폰으로 연락 → 용사가 치과에 전화해서 예약
- 예약·접수는 전부 **군 인트라넷**이라 외부 인터넷과 연동 불가 → 사이트에서 예약을 받거나 개인정보를 수집하지 않음

## 2. 먼저 고칠 것 (보안·신뢰)

- [ ] `data/schedule.json`과 달력에 **군의관 실명별 부재 일정이 공개**되어 있음 → 이름 없이 "초진 가능 / 재진만 / 휴진" 정도로 축소하거나 제거. 공개 전 부대 보안담당관 확인 권장
- [ ] 병사 실명·학력 공개 제거, 역할만 남기기 ("UPenn 의료과"는 실제 없는 학과명)
- [ ] 광고성 표현 제거: "대학병원급", 3M·이노톡스·티엠버스 제품 사진, "내성이 적고 안전한 보톡스"

## 3. 내용 수정

- [ ] "개인 휴대폰으로는 내선에 못 건다"는 점 명시. 휴대폰으로 걸 수 있는 일반 번호가 있으면 함께 적고 `tel:` 링크 추가
- [ ] **"전화할 때 이렇게 말하세요" 카드** 추가: 소속 / 계급·이름 / 군번 / 용건. 캡처하거나 적어 가라고 안내
- [ ] **보철 안내** 추가: 본뜨기·임시치아 → 도착 연락 → 다음 일과 중 전화 예약 → 장착(약 30분). 임시치아가 빠졌을 때 대처, 장착이 오래 늦어지면 재제작될 수 있다는 점, 휴가·훈련과 겹칠 때
- [ ] 주의사항 보강: 보톡스 후, 교합안정장치 사용·세척, 크라운·인레이 장착 후
- [ ] (선택) "내 예약 캘린더에 추가" 버튼: 날짜·시간 입력 → .ics 파일 생성. 브라우저 안에서만 처리하고 서버 전송 없음
- [ ] OG 태그(`og:title`, `og:description`, `og:image`) 추가 → 카톡 링크 미리보기용
- [ ] 자잘한 것
  - 오후 진료 13:00 시작인데 출석 체크 13:30 → 하나로 정리
  - "상검" 용어 풀어 쓰기
  - 신경치료 안내에 복붙된 "심한 출혈 같은 응급" 문구 수정
  - 발치 후 "뱉지 마세요"와 "양치액 머금었다 뱉기" 충돌 → 양치액은 "다음 날부터"로 명시
  - 빠진 치아 "한 시간 안이면 다시 심을 수 있다" → "빠를수록 좋다, 뿌리는 만지지 말 것"
  - 하단 "그림은 임시로 그린 것" 문구 삭제
  - 장식용 치식표 SVG에 `aria-hidden="true"`

## 4. 디자인 방향

- 문제점
  - 모바일 첫 화면이 일러스트로 꽉 차서 페이지 제목이 두 번째 화면에야 나옴
  - 일러스트가 와이어프레임처럼 보임
  - 흑백 줄무늬 띠와 회청색 판 사이 틈
  - 한글 양쪽 정렬로 단어 간격 벌어짐
  - 홈이 휴대폰 기준 약 17화면 분량
- 방향: 개인 병원 사이트의 **절제(여백·타이포)만** 가져오고, 구조는 **공공기관 안내 페이지처럼 찾아보기 쉽게**
- 토큰 (시안 기준)
  - 바탕 `#FFFFFF`, 글자 `#101828`, 보조 글자 `#556070`, 구분선 `#E5E8ED`, 옅은 면 `#F4F6F9`
  - 포인트 `#1B3F7A` (버튼·라벨·칩에만)
  - 경고 박스 바탕 `#FFF3E0`, 경고 글자 `#9A3412`
  - 하세요 아이콘 `#15803D`, 하지 마세요 아이콘 `#B42318`
  - 글꼴 Pretendard 유지, 양쪽 정렬 금지(왼쪽 정렬)
  - 제목 위 작은 영문 대문자 라벨 (예: `AFTER CARE`, `01 · EXTRACTION`)
- 레이아웃
  - 얇은 고정 헤더: 왼쪽 작은 마크와 이름, 오른쪽 메뉴·전화
  - 부대 마크는 헤더에 작게 한 번만
  - 회청색 바닥색과 줄무늬 띠 삭제
- 주의사항 페이지 구조: 제목 → 바로가기 칩(발치·신경·보철·마취·스케일링·치료 전) → 응급 박스 → 시술별 섹션(요약 태그 + "이렇게 하세요 / 하지 마세요") → 전화 스크립트 카드
- 홈 구조: 짧은 히어로 → 오늘 진료 상태 → 2×2 바로가기(주의사항 / 보철물 도착 / 시간·예약 / 진료 과목) + 응급 줄 → 의료진 → 예약 3단계 → 연락처
- 사진: 군의관 프로필은 같은 배경·조명·복장으로 촬영. 실제 진료실 사진 2~3장으로 무료 이미지 교체

## 5. 브리프 (Taste 스킬용)

```
대상: 카톡 링크로 휴대폰에서 여는 20대 용사. 일과 후 저녁에 읽고 다음 날 군 전화로 예약함.
느낌: 차분하고 믿음직한 공공 의료 안내. 홍보·감성 카피 금지.
참고: 정부·공공기관 안내 페이지의 정보 구조 + talentdentist.com의 여백과 타이포만.
Taste: VARIANCE 2, MOTION 1, DENSITY 7.
확인: Playwright로 390px·1440px 캡처 후 "첫 화면에 제목이 보이는지", 넘침, 정렬을 고치고 전후 비교.
```

참고: 현재 사이트에 `npx impeccable detect`를 돌린 결과 AI 티 항목은 0개였음. 문제는 AI 티가 아니라 목적에 맞는 구조와 우선순위임.

## 6. 작업 순서 제안

1. 2번(보안) 먼저 반영
2. `care.html`을 시안대로 재구성하고 `style.css` 토큰 정리
3. 모바일·데스크톱 캡처로 확인
4. 같은 방식으로 홈 → 시간·예약 → 진료 안내 순서로 적용
5. 보철 안내 페이지 또는 섹션 추가, OG 태그 추가
